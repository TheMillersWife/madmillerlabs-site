# madmillerlabs-site
A home lab simulating an enterprise corporate merger between two independent Active Directory forests. Built on a Dell PowerEdge R640, Nutanix CE, pfSense, and a Cisco Catalyst 2960X.
This repository hosts the public portfolio site for Mad Miller Labs — documenting architecture decisions, builds, and security scenarios as the lab grows.
Current focus: Cross-forest Active Directory trust, network segmentation, and security monitoring.
